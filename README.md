# Español en Bici 🚵

אפליקציית רשת ללימוד ספרדית של ספרד מאפס, דרך הרפתקת אופני הרים.

- ממשק בעברית, ספרדית עם הקראה קולית (es-ES)
- פרק 1 (ברצלונה): 6 שיעורים, פעלול חדש בכל שיעור
- משימות משפחה, תרגול חוזר ממוקד בטעויות, נקודות ורצף ימים
- קובץ יחיד: `index.html`, ללא תלויות. ההתקדמות נשמרת בדפדפן (localStorage).

הוספת שיעור: מוסיפים אובייקט ל-`LESSONS` ואת המזהה שלו ל-`lessons` של הפרק ב-`CHAPTERS`.
